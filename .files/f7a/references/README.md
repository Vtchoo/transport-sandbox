# Real F7A photo references

The selected v5 generation (`iterations/05-photo-reference`) used the two
user-attached photographs of Santa Fe No. 49 directly, together with the v5 UV
guide. It did not use an earlier generated texture. The attached photographs
remain in the conversation; they have no workspace file paths.

These additional reference photographs were downloaded as 1280px Wikimedia
previews during research. They are not the inputs to the selected generation:
